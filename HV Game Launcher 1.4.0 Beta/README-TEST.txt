HV Game Launcher 1.4.0 Beta - Stage 1.3

Changes in this stage:
- Reduced the cover column width and constrained the cover image to its original aspect ratio.
- The cover is centered in its panel with no stretched image or black letterbox bars.
- The launcher title now follows the selected Launch button color.
- Removed the blue underline below the launcher title.

Build:
1. Run Build.bat on Windows with the .NET 8 SDK installed.
2. Run the published Launcher.exe.

Existing config.ini and launcher.settings behavior is retained.

Stage 1.5: Reduced the Launch button size to 230x60 and adjusted its font to 15pt.
