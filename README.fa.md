# HV Game Launcher

یک لانچر قابل‌شخصی‌سازی برای بازی‌های ویندوزی که با C#، فریم‌ورک Avalonia و .NET 8 ساخته شده است.

## امکانات

- اجرای فایل اجرایی بازی که مسیر آن در تنظیمات مشخص شده است.
- اجرای اسکریپت VBS تنظیم‌شده از منوی Launch.
- انتخاب رنگ اصلی لانچر و جابه‌جایی بین تم‌های روشن و تاریک.
- استفاده از تصویر کاور، لوگو، آیکون برنامه و تصویر پس‌زمینهٔ جداگانه برای هر تم.
- تنظیم مسیر بازی و تصاویر در فایل `config.ini`.
- پشتیبانی از مسیرهای مطلق و مسیرهای نسبی نسبت به پوشهٔ لانچر.

## پیش‌نیازها

### برای ساخت برنامه از سورس

- ویندوز ۶۴ بیتی
- .NET 8 SDK

### برای اجرای نسخهٔ منتشرشده

- ویندوز ۶۴ بیتی
- .NET 8 Runtime نسخهٔ ۶۴ بیتی

نسخهٔ منتشرشده به‌صورت framework-dependent است و Runtime دات‌نت را همراه خود ندارد؛ بنابراین Runtime باید جداگانه نصب شود. فایل پروژه در حال حاضر برای `net8.0-windows` و `win-x64` تنظیم شده است.

## ساخت برنامه

۱. .NET 8 SDK را نصب کنید.
۲. ترمینال را در پوشه‌ای باز کنید که فایل `HV.GameLauncher.csproj` در آن قرار دارد.
۳. دستور زیر را اجرا کنید:

```powershell
dotnet publish HV.GameLauncher.csproj -c Release
```

۴. فایل‌های انتشار در پوشهٔ `Publish/HV Game Launcher/` قرار می‌گیرند.
۵. فایل `config.ini` و تصویرهایی را که در آن معرفی کرده‌اید، کنار `Launcher.exe` نگه دارید یا برای آن‌ها مسیر مطلق وارد کنید.

## تنظیمات

پیش از اجرای برنامه، فایل `config.ini` را ویرایش کنید:

```ini
[Paths]
GameEXE=
VBSFile=

[Appearance]
Icon=
Logo=
Cover=
BackgroundLight=
BackgroundDark=
```

مسیر فایل اجرایی بازی را در `GameEXE` و مسیر اسکریپت VBS را در `VBSFile` وارد کنید. گزینه‌های ظاهری اختیاری هستند. می‌توانید مسیر نسبی نسبت به پوشهٔ لانچر یا مسیر مطلق وارد کنید. با `BackgroundLight` و `BackgroundDark` می‌توان برای دو تم، تصویر پس‌زمینهٔ جداگانه تعیین کرد.

## دربارهٔ پروژه

HV Game Launcher یک پروژهٔ شخصی و سرگرمی است که با کمک نسخهٔ رایگان ChatGPT ساخته شده است. سازنده پیشینهٔ رسمی برنامه‌نویسی ندارد و این برنامه را از روی علاقه و کنجکاوی شخصی و با کمک هوش مصنوعی توسعه داده است.
